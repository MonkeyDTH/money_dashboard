# V0.1.3 移动端适配

**日期**：2026-05-25
**状态**：设计稿，待实现

---

## 一、背景与动机

当前界面为纯桌面布局：左侧固定宽度导航栏 `w-56`、主内容区 `px-8`、多列 grid、宽表格。在手机端（< 640px）这些布局直接溢出或被压缩，无法正常使用。

核心痛点：
1. 左侧导航占用全屏 25% 宽度，主内容区被严重压缩
2. `grid-cols-3` 指标卡片和图表行在小屏幕上每列过窄
3. 账户表格有 6 列，余额录入表格 input 宽 `w-44`，横向溢出
4. 顶栏 header 的 `px-8` 和按钮在小屏幕下拥挤

---

## 二、方案设计

### 2.1 整体策略

采用 **移动端底部 Tab 导航 + 桌面端保持左侧导航** 的双模式：

- `sm:` 以上（≥ 640px）：保持现有左侧导航不变
- `< 640px`（移动端）：左侧导航隐藏，底部固定 Tab 栏替代

### 2.2 base.html 改动

**左侧导航**：加 `hidden sm:flex` 使其在移动端隐藏

**主内容区**：
- `flex-1 overflow-y-auto` 保持
- 顶栏 `px-8` → `px-4 sm:px-8`
- 页面内容 `px-8 py-6` → `px-4 py-4 sm:px-8 sm:py-6`
- 移动端底部留出 Tab 栏高度，加 `pb-16 sm:pb-0`

**移动端底部 Tab**：新增一段 HTML，只在 `< sm` 显示（`sm:hidden`），包含 6 个导航项，图标 + 文字，固定在底部。

### 2.3 dashboard/index.html 改动

| 区域 | 当前 | 移动端 |
|------|------|--------|
| 指标卡片行 | `grid-cols-3` | `grid-cols-1 sm:grid-cols-3` |
| 图表行 | `grid-cols-3`，趋势图 `col-span-2` | `grid-cols-1 sm:grid-cols-3`，趋势图取消 col-span 在移动端 |
| 图表高度 | 固定 `220px` | 保持，ECharts 会自动 resize |

### 2.4 account_table.html 改动（账户列表）

6 列表格在移动端处理方式：隐藏次要列（货币、状态），保留账户名、类型、操作。

| 列 | 移动端 |
|----|--------|
| 账户名称 | 保留 |
| 类型 | 保留 |
| 归属 | `hidden sm:table-cell` |
| 货币 | `hidden sm:table-cell` |
| 状态 | `hidden sm:table-cell` |
| 操作 | 保留 |

### 2.5 snapshots/entry.html 改动（余额录入）

- 余额输入框 `w-44` → `w-32 sm:w-44`
- 表格列头"类型"：`hidden sm:table-cell`
- 表格数据"类型"：`hidden sm:table-cell`

### 2.6 salaries/list.html 改动（薪资列表）

| 列 | 移动端 |
|----|--------|
| 月份 | 保留 |
| 公司 | `hidden sm:table-cell` |
| 应发 | `hidden sm:table-cell` |
| 实发 | 保留 |
| 查看明细 | 保留 |

## 四、验证方式

1. 浏览器 DevTools → 切换到 iPhone SE（375px）宽度检查各页面
2. 底部 Tab 导航高亮状态与桌面端左侧导航逻辑一致
3. 表格横向无溢出（无横向滚动条）
4. 图表在移动端正常渲染并响应 resize
