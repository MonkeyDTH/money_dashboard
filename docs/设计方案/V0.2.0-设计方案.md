# 支出录入 + 其他收入录入 V0.2.0

**创建时间**: 2026-05-25 18:27
**背景**: Phase 2 第一步，补全收支录入能力，为后续收支结余图（V0.2.1）提供数据基础。

---

## 1. 总体方案

新增两个录入模块：

| 模块 | 说明 |
|------|------|
| 月度支出录入 | 按 3 个大类录入当月支出，区分家庭/个人归属 |
| 其他收入录入 | 记录薪资以外的收入，金额 + 备注 + 归属 |

导航栏新增"收支"入口，进入后展示当月收支录入页。

---

## 2. 数据模型

### 2.1 ExpenseCategory（支出大类）

原设计方案已有此表，V0.2.0 不改结构，仅在初始化时预置 3 条记录：

| id | name | sort_order |
|----|------|------------|
| 1 | 生活消费 | 1 |
| 2 | 固定支出 | 2 |
| 3 | 特别支出 | 3 |

`color` 字段保留，暂不使用。

### 2.2 MonthlyExpense（月度支出）

原设计方案已有此表，字段无需变更：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| category_id | int | 关联大类 |
| period | date | 归属月份（月末） |
| amount | decimal(14,2) | 当月支出金额 |
| owner_type | enum | family / member |
| owner_member_id | int? | 个人支出时关联成员 |
| note | text | 备注 |

唯一约束：`(category_id, period, owner_type, owner_member_id)`

### 2.3 OtherIncome（其他收入）— 新增表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| period | date | 归属月份（月末） |
| amount | decimal(14,2) | 金额 |
| owner_type | enum | family / member |
| owner_member_id | int? | 个人收入时关联成员 |
| note | text | 备注（来源描述，如"租金"、"副业"） |
| recorded_at | datetime | 录入时间 |

> 其他收入不分类，note 字段承担来源说明职责。同一月份可录入多条（一对多）。

## 3. 页面设计

### 3.1 导航入口

左侧导航 / 移动端底部 Tab 新增**"收支"**项，图标用收支类图标，路由 `/expenses`。

### 3.2 收支录入页（`/expenses`）

页面顶部：月份选择器（默认当月），与余额录入页保持一致的交互风格。

**支出区块**

表格形式，行 = 支出大类，列 = 家庭 / 个人（仅本人）：

```
月度支出 — 2026年5月

          家庭共同        个人
生活消费  [______元]  [______元]
固定支出  [______元]  [______元]
特别支出  [______元]  [______元]
                        [备注]
```

- 每格独立填写，为空则不写入（不存 0 值）
- 每行最右侧可选填备注

**其他收入区块**

列表形式，支持当月多条：

```
其他收入 — 2026年5月

[+ 添加收入]

归属     金额        备注         操作
家庭    3000元    4月租金收入    [删除]
个人    500元     稿费          [删除]
```

- 点击"添加收入"弹出行内表单（归属下拉 + 金额 + 备注）
- 使用 HTMX 局部刷新，无需整页刷新

### 3.3 交互细节

- 支出表格：失焦自动保存（HTMX POST），与余额录入页逻辑一致
- 其他收入：添加后立即显示在列表，可删除
- 已录入数据再次进入页面时自动回填

## 5. 验证方式

1. 进入收支页，录入家庭共同"生活消费"2000 元，刷新后数据保留
2. 同月录入个人"固定支出"，两条数据互不影响
3. 添加两条其他收入，归属分别为家庭和个人，均正常显示
4. 删除一条其他收入，列表立即更新
5. 切换月份，数据按月独立显示
