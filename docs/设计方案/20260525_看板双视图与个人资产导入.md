# 看板双视图 + 个人资产历史数据导入

**日期**：2026-05-25
**状态**：设计稿，待实现

---

## 一、背景与动机

用户同时维护两套账户体系：
- **家庭共同账户**：已在数据库中，owner_type=family
- **个人账户**：来自历史 Excel 文件（2020-05 至 2026-04，共 68 个月），owner_type=member

两者资产规模、构成完全不同，混在一张看板上会互相干扰，需要在 UI 上隔离展示。

---

## 二、方案设计

### 2.1 看板双视图

**交互方式**：首页顶部加"家庭 / 个人"Tab，默认"家庭"。

Tab 切换通过 URL query 参数 `?view=family`（默认）/ `?view=personal` 控制，服务端渲染，无需 HTMX。好处是可以直接分享/书签到具体视图。

**数据过滤逻辑**：

| 视图 | 快照过滤条件 |
|------|------------|
| family | Account.owner_type == 'family' |
| personal | Account.owner_type == 'member' AND Account.owner_member_id == self_member_id |

两个视图的图表（净资产趋势、资产配置、收入柱状图）完全独立计算，互不影响。

收入柱状图（薪资）在两个视图下显示相同数据（薪资天然属于个人，不需要区分）。

### 2.2 账户列表页区分展示

账户列表（`/accounts`）按归属分成两个分组展示：
- **家庭共同**：owner_type=family 的账户
- **个人**：owner_type=member 的账户

### 2.3 个人账户和历史数据导入

**新建 7 个个人账户**（owner_type=member, owner_member_id=is_self 的成员 id）：

| Excel 列 | 账户名 | 账户类型推断 |
|---------|-------|------------|
| 现金 | 现金（个人） | 现金 |
| 农行卡 | 农行卡 | 活期 |
| 招行卡 | 招行卡 | 活期 |
| 其他银行 | 其他银行 | 活期 |
| 蚂蚁财富 | 蚂蚁财富 | 货币基金 |
| 微信理财通 | 微信理财通 | 货币基金 |
| 蛋卷基金 | 蛋卷基金 | 基金 |

> 账户名加"（个人）"后缀只针对"现金"，避免与家庭的现金账户混淆；其余名字唯一，不加后缀。

**月度快照生成规则**：
- Excel 是周度数据，每个自然月取**日期最大的那一行**作为当月快照
- period 统一存该月最后一天（如 2020-05-31）
- 余额为 None 或 0 的账户该月不写入快照（避免早期账户未开立时产生 0 值干扰）
- 导入幂等：按 (account_id, period) 唯一索引，已有则跳过

**以一次性 Python 脚本执行**（`app/scripts/import_personal_assets.py`），不改动导入导出路由。

## 三、代码变更清单

| 文件 | 变更内容 |
|------|---------|
| `app/routers/dashboard.py` | 接收 `view` query 参数，按 owner_type 过滤快照查询 |

---

## 四、验证方式

1. 首页默认显示"家庭"视图，净资产曲线与导入前一致
2. 切换到"个人"视图，净资产曲线显示从 2020-05 开始的个人资产历史
3. 两个视图的当前净资产数字分别正确（不互相影响）
4. 账户列表页可见两个分组，个人账户 7 条在"个人"组
5. 脚本重复执行不报错、不重复插入数据
