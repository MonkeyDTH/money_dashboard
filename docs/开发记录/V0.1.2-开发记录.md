## 3. 设计决策记录

### 3.1 公积金充值的方向归属

飞书表格中"公积金充值"为正数（如 2996、4340），而"五险一金个人"为负数。数学验证：

```
实际到手 = 合同工资 + 奖金 + 补贴 + 五险一金个人 + 个税扣除
```

公积金充值不参与上述等式，说明它记录的是每月公积金账户入账总额（含单位部分），而非从工资扣除项。因此存为 `housing_fund + direction=income`，独立追踪公积金账户累积，不影响应发/实发计算。

### 3.2 飞书 Base 授权域

飞书 Base 操作需要独立的 `base` domain 授权（`lark-cli auth login --domain base`），与 IM / Drive 授权相互独立。首次使用前必须完成此步骤。

### 3.3 period vs pay_date

模型中 `period` 为工资归属月末，`pay_date` 为实际发薪日。爱奇艺/阿里记录的日期本身即月末，友塔为每月 15 日，十三薪等特殊款项发薪日不固定——统一以飞书原始日期作为 `pay_date`，再推算对应月末作为 `period`。
