## 1. 版本目标

将应用部署到家庭 NAS（QNAP），配置国内镜像源以解决网络访问问题，并沉淀运维操作文档。

## 2. 主要变更

- Docker 基础镜像和 uv 工具镜像切换为 DaoCloud 国内代理，解决 NAS 无法翻墙的问题
- Python 依赖安装改用清华 PyPI 镜像，并启用 BuildKit 缓存加速后续构建
- 服务对外端口从 8000 改为 7335
- 新增 NAS 运维手册，记录 SSH 免密登录、文件传输、Docker 常用命令等操作方式

## 3. 设计决策记录

### 3.1 镜像代理选型：DaoCloud

DaoCloud（`docker.m.daocloud.io` / `ghcr.m.daocloud.io`）是目前国内稳定性较好的 Docker 镜像代理，同时支持 DockerHub 和 ghcr.io，覆盖本项目的两个镜像来源。

### 3.2 BuildKit 缓存挂载

使用 `--mount=type=cache,target=/root/.cache/uv` 挂载 uv 缓存目录。首次构建需全量下载依赖，后续构建只要 `pyproject.toml` / `uv.lock` 不变，`uv sync` 步骤可在数秒内完成。

## 4. 遇到的问题及解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Docker build 报错 `/static: not found` | `static/` 目录为空，Git 不追踪空目录，NAS 上 `git pull` 后该目录不存在 | 在 NAS 上手动 `mkdir static` |
